About This Project

Biological databases like UniProt contain millions of annotations. Many are inferred from other annotations rather than tested experimentally. When a source is wrong, the error silently propagates through every downstream entry.

What We Track

  • Evidence codes — how do we know this?
  • Cross-references — which databases contributed?
  • Citation chains — which papers back this up?
  • Retraction status — has any source been retracted?

Tech Stack

Static frontend · UniProt REST API · Crossref API · open data only.
